# Après une maintenance

## Symptômes

Après une annonce de maintenance : ancien écran, erreur étrange, ou session déconnectée.

## Que faire

1. Se **déconnecter** puis se reconnecter.
2. **Hard refresh** : Windows/Linux `Ctrl+F5` · Mac `Cmd+Shift+R`.
3. Vider le cache du navigateur **seulement** si l’ops vous l’indique.
4. Vérifier que vous êtes bien sur `https://polyspace.mr` (pas le site de test).

## Escalade

Si le problème continue après refresh et reconnexion → contacter l’ops avec l’heure de fin de maintenance annoncée.
