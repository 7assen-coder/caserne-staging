## Gravité

| Code | Signification | Exemple |
|------|---------------|---------|
| **P0** | Tout le monde bloqué | Site ou API inaccessible |
| **P1** | Fonction importante dégradée | Connexion lente pour tous, exports en panne |
| **P2** | Gêne limitée | Un poste, un navigateur, environnement de test |

## Avant d’appeler

1. Ouvrir `https://status.polyspace.mr` — y a-t-il une alerte ?
2. Essayer un autre navigateur ou le réseau mobile (pas seulement le Wi‑Fi caserne).
3. Noter l’heure, le message d’erreur exact, et votre adresse e-mail `@esp.mr`.

Environnement de **test** (`polyspace.onrender.com`) : bandeau jaune — ne pas traiter comme la production.
